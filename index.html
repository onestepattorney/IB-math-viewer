Connect to your private repository

The question images stay in your private GitHub repository. This page fetches them only when you open a question, using a read-only token that is stored in this browser only.

  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Expiration: 90 days. Repository access: Only select repositories → IB-math.
  3. Permissions → Repository permissions → Contents: Read-only (nothing else).
  4. Generate, copy the token and paste it below.
